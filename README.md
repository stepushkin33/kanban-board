# Kanban Board

Канбан-доска на Webpack, React и TypeScript. Карточки сгруппированы по статусу и отсортированы по дате начала. Начальные данные берутся из [tasks.json](tasks.json).

## Запуск

Требуются Node.js 18.18.0 и npm.

```sh
nvm use
npm ci
npm run start
```

Dev-сервер слушает [127.0.0.1:8080](http://127.0.0.1:8080). Для статической публикации `npm run build` собирает приложение в `dist/`.

## Работа с доской

- Выполненную задачу можно перенести в другой столбец тем же способом, что и остальные. При переносе меняется статус, а позиция определяется датой начала.
- Наведите указатель на карточку или переведите на неё фокус, чтобы увидеть кнопки редактирования и удаления. На сенсорном экране эти кнопки всегда доступны. Новую карточку можно создать кнопкой «Добавить» в столбце To Do.
- Для переноса с клавиатуры нажмите пробел на карточке, выберите столбец стрелками ← и → и подтвердите пробелом. Escape отменяет перенос. Статус также можно изменить в форме редактирования.
- Поиск по описанию работает без учёта регистра. Полная дата в формате `дд.мм.гггг` ищется среди дат начала и окончания.
- Даты из JSON и формы хранятся как Unix timestamps в миллисекундах. Дату карточки читаем по UTC, чтобы одна и та же запись выглядела одинаково в разных часовых поясах. Просрочка начинается, когда в часовом поясе браузера наступает следующий календарный день. Карточки Done не выделяются.
- Изменения хранятся в `localStorage` этого браузера, в том числе состояние доски после удаления всех задач.

## Проверки

| Команда                | Проверка                              |
| ---------------------- | ------------------------------------- |
| `npm run test`         | Модульные и интеграционные тесты      |
| `npm run lint`         | ESLint, Stylelint и TypeScript        |
| `npm run format:check` | Форматирование Prettier               |
| `npm run format`       | Применение форматирования             |
| `npm run check`        | Форматирование, линтеры, типы и тесты |

Модульный тест функции просрочки расположен в [src/tasks/is-task-overdue.test.ts](src/tasks/is-task-overdue.test.ts).

## Структура

- `src/tasks/` содержит типы задач, работу с датами, поиск, сортировку и сохранение.
- `src/board/` содержит компоненты карточек, столбцов, поиска и формы, а также логику перетаскивания.
- `src/App.tsx` связывает состояние с интерфейсом.

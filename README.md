# Kanban Board

Канбан-доска на React, TypeScript и Webpack.

Начальные данные берутся из [tasks.json](tasks.json).
Дополнительно добавлена возможность переставлять карточки по вертикали для контроля над приоритетностью.

## Запуск

Требуются Node.js 18.18.0 и npm.

```sh
nvm use
npm ci
npm run start
```

Dev-сервер слушает [localhost:8080](http://localhost:8080/).
Для статической публикации `npm run build` собирает приложение в `dist/`.

## Проверки

| Команда                | Проверка                                                      |
| ---------------------- | ------------------------------------------------------------- |
| `npm run test`         | Модульные и интеграционные тесты                              |
| `npm run lint`         | ESLint с Boundaries, Stylelint для SCSS, Steiger и TypeScript |
| `npm run lint:fsd`     | Границы слоёв и публичные API срезов                          |
| `npm run format:check` | Форматирование Prettier                                       |
| `npm run format`       | Применение форматирования                                     |
| `npm run check`        | Форматирование, линтеры, типы и тесты                         |

Тест правила просрочки находится в [is-task-overdue.test.ts](src/entities/task/model/is-task-overdue.test.ts).

## Структура FSD

- `app` запускает приложение и подключает общие стили.
- `pages/board` собирает страницу доски и связывает её с состоянием.
- `widgets/task-board` отвечает за колонки, карточки и перетаскивание.
- `features` содержит поиск и форму редактирования задачи.
- `entities/task` описывает задачи, сроки, порядок карточек и хранение.
- `shared` содержит календарные функции и иконки.

Стили компонентов находятся рядом с компонентами в файлах `*.module.scss`. Общие стили приложения подключаются из `app/styles/base.scss`.

Между срезами используйте алиас `@/` и публичные экспорты из `index.ts`. Внутри среза используйте относительные импорты.

Steiger проверяет структуру FSD, а ESLint Boundaries дополнительно контролирует импорты и реэкспорты. Правило `fsd/insignificant-slice` отключено для одностраничного приложения, чтобы поиск, редактор и доска оставались самостоятельными срезами.
